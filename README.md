# davidemaggi/tap

Homebrew casks for [Davide Maggi](https://github.com/davidemaggi)'s apps.

```bash
brew install --cask davidemaggi/tap/<name>
```

| Cask | App |
| ---- | --- |
| `hodor` | [Hodor](https://github.com/davidemaggi/Hodor): Kubernetes port-forwards as templates, on any cluster |
| `queuecumber` | [QueueCumber](https://github.com/davidemaggi/QueueCumber): see what's flowing through RabbitMQ and Kafka without borrowing an application's consumer (Apple silicon only until a release ships an Intel build) |

The casks are written and updated by each app's release workflow, from the files on its GitHub release: don't edit them by hand, the next release would overwrite the change.
